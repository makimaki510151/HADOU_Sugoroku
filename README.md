# 覇道すごろく

職を選んで、100マスの一本道を先に踏んだ人が勝つ **P2Pすごろく** です。GitHub Pages にそのまま置けます。

## 遊び方

1. **部屋を作る（ホスト）** → 出た部屋コードを渡す
2. 相手は **部屋に入る** で同じコード
3. ホストが「ゲーム開始」（足りなければ CPU を足す）
4. 自分の番にスキルを好きなだけ使ってからダイス。先に100マス目へ乗った人の勝ち（ぴったり不要）
5. 2ラウンド目から、最下位はダイス+1。1位以外は強化を3枚から1枚選ぶ

このブラウザだけで CPU とも遊べます。`?demo=match` で、自分＋CPU3人の対局に入れます。

## ルール概要

| 要素 | 内容 |
| --- | --- |
| 勝利 | 100マス目に先に到達。マスを余しても勝ち |
| 職 | ヴァンガード / トラップマスター / アサシン / ギャンブラー / マグネット / ランナー。初期HP・ダイス・スキル4つ（常時1・通常2・必殺1）。タイトルの職一覧で確認 |
| HP | お金の代わり。0で次の自分の番を1回休み、その次に最大HPまで回復して復帰。初期は盾12、罠10、刃8、運10 |
| 盤 | 空マスが基本。スキルでスパイクや呪印、加速床を置く。マークがあるマスはタップで中身がわかる |
| ラウンド | 全員が1回ずつ動くと終了。2ラウンド目以降に劣勢救済 |
| オンライン | 部屋コード。バージョンが一致しないと入れない。同じ名前で再接続。20秒戻らなければCPU代打 |

## GitHub Pages

Settings → Pages で Branch を `main`、Folder を `/ (root)`。

公開URL例: `https://makimaki510151.github.io/HADOU_Sugoroku/`

## 開発

ビルド不要です。

```bash
python3 -m http.server 8080
```

テスト:

```bash
node --test tests/*.test.mjs
```

## 技術

- 純フロントエンド（ES Modules）
- 描画: Canvas 2D
- 通信: [PeerJS](https://unpkg.com/peerjs@1.5.4/dist/peerjs.min.js)（WebRTC DataChannel、ホスト権威の状態同期）
- 効果音とBGM: Web Audio の発振（外部サンプルなし）
